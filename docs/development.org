* Development
:PROPERTIES:
:CUSTOM_ID: development
:END:

The project uses [[https://github.com/jjba23/maak][maak]]; each task is one command:

#+begin_src shell
maak            # the whole gate: clean, lint, unit suite
maak lint       # byte-compile with warnings as errors, then checkdoc
maak test       # the unit suite
maak integration # the same checks against a real MPD and a real mpv
maak demo       # record screenshots/orpheus-demo.gif under Xvfb
maak release -- minor # bump, close NEWS, gate, commit, tag, push, publish
maak repl       # Emacs with the package loaded and the player open
#+end_src

GitHub Actions runs the gate on every push to ~trunk~ and every pull request:
the unit suite on Emacs 29.1 and 31.1, the integration suite against a real
~mpd~ and a real ~mpv~, and lint.  The workflow spells the commands out because
maak is not installed there.

~maak demo~ runs =scripts/record-demo.sh=: Emacs under Xvfb draws a fixed
library through the real interface, once per theme, and ffmpeg assembles the
frames into =screenshots/orpheus-demo.gif=.  It needs ~xvfb-run~, ~ffmpeg~ and an
Emacs built with cairo, which is what lets Emacs export each frame as a PNG; it
needs no player, daemon or network.  The demo data is fixed, so a checkout
records the same scenes; the font is the one machine-dependent input.

The repository carries that environment as =manifest.scm= for Guix and
=flake.nix= for Nix.  Both include Xvfb, ffmpeg, DejaVu Sans Mono and a
Cairo-capable Emacs.  The Nix shell records the GIF end to end:

#+begin_src shell
nix develop --command bash scripts/record-demo.sh
#+end_src

The Guix manifest supplies the same tools, but on Guix 1.5 its Emacs/GTK build
currently hangs while the demo opens its first frame; use the Nix shell to
record until that is resolved.

~maak release~ refuses a dirty or unsynced ~trunk~ and maak's ~--dry-run~,
closes the ~* Unreleased~ heading with today's date, runs the full gate, commits
the release, tags ~vX.Y.Z~, pushes both, and creates the GitHub release.  It
takes an explicit version or ~patch~, ~minor~ or ~major~; ~gh~ must already be
authenticated.

The unit suite needs nothing but Emacs: it starts a fake MPD in the same
process, on a loopback port, and speaks the protocol at it — greeting,
password, replies queued before the connection is ready, ~ACK~ errors, a unix
socket, and a binary album-art payload.  The integration suite starts real
programs in a temporary directory and skips itself when ~mpd~, ~mpv~ or
~ffmpeg~ are missing.

=AGENTS.md= is generated by ~maak agents~ from the pinned skills in
=maak.scm=; edit that task, never the generated file.
